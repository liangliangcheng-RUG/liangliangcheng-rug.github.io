# Cheng Group GitHub Pages 主页

这是一个可直接发布到 GitHub Pages 的静态学术主页，内容根据 `Cheng group.docx` 整理，视觉参考了 `kailaili.github.io` 这类简洁学术主页。

## 文件结构

- `index.html`: 网站首页和全部内容
- `styles.css`: 响应式样式
- `assets/`: logo、头像、项目资助方 logo

## 发布到 `https://liangliangcheng.github.io/`

1. 打开或创建 GitHub 仓库：`liangliangcheng/liangliangcheng.github.io`
2. 把本文件夹里的所有内容复制到该仓库根目录。
3. 提交并推送到 GitHub。
4. 在 GitHub 仓库中进入 `Settings > Pages`。
5. Source 选择 `Deploy from a branch`，branch 选择 `main`，folder 选择 `/root`。
6. 等待 GitHub Pages 部署完成，然后访问 `https://liangliangcheng.github.io/`。

如果已经有旧网站，建议先备份旧仓库内容，再用这些文件替换。

## 建议发布前核对

- `People` 页面中个别成员邮箱可能来自 Word 文档里的临时占位或重复邮箱，建议确认后再发布。
- `News` 目前使用项目和论文信息整理为按年份的 selected updates；如果有精确日期，可以继续补成月/日。
- `Publications` 已保留 Word 文档中的 2023 年以来条目，部分 preprint 或 `DOI to be verified` 项建议后续更新链接。
